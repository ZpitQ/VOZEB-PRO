# M3 Windows 内网验收收口

当前 M3 内网功能和最终安装／来源材料已完成交付，详见 [M3 交付清单](2026-10-23-image-super-resolution-m3-delivery.md)。下述实机范围保持；新外层最终清单与历史候选标记分别保存，用户最终使用确认独立记录。

适用范围是管理员维护、常在线的 Windows GPU 服务，默认 HTTP＋Token。安装、升级、恢复使用 Windows 服务和现有事务；不新增启动证明握手、系统 SID 证明、逐文件权限兼容矩阵或整机断网测试。

## 当前功能结果

| 项目 | 已取得的实际结果 |
| --- | --- |
| 后台 GPU 与自动启动 | 固定服务账户、Session0、Auto；真实 GPU 将 1254×1254 增强为 5016×5016，完整图片校验及新实例自检通过。实际开发后端曾完成认证、下载解码及唯一自检调用。 |
| 重启与任务恢复 | Windows 重启后配置、稳定身份、已有任务与结果保留；独立服务另验排队任务跨重启，以及运行任务中断后沿同一任务和原截止时间恢复。 |
| 调用链路异常 | 原接口连接拒绝、上传超时、下载期间调用方超时及恢复下载分轮通过；执行期间新增单次本地转发响应断连，随后 GET 原任务完成，未重复超分。该新增场景不等于切断引擎或整机网络。 |
| 升级与恢复 | 标准升级、完整健康备份、显式回退、坏包拒绝、不兼容数据先只读拒绝及一次真实升级失败后的显式恢复均已分轮验证。 |
| 忙时卸载 | 执行任务时先返回 `worker_not_quiescent`；任务自然成功后，同一维护操作继续卸载，默认保留任务、原图、配置、模型和凭据。 |
| 保留重装 | 标准 retained Install 复用原安装与服务身份，不重新初始化或发钥；新实例唯一 GPU 自检通过，24 个历史任务、151 份记录及原图保持，两份指定结果完整下载通过。 |
| 显式删数据 | 在新建的隔离 retained 副本上执行一次 `DeleteData`，原安装完整数据和记录保持。此项不是第二套完整安装，也未删除现有任务。 |
| 诊断 | 安装维护失败保留阶段、异常类型与 Windows 数值错误码；不回显 Token 或异常原文。程序目录的诊断不阻挡业务数据删除。 |

最新重装实例已合格、可接单且空闲，共保留 25 个任务和 157 份记录。每个新启动实例单独取得 GPU 资格；`startupRecovery=settled` 只描述启动恢复阶段，仍须另查任务终态、执行槽与引用，不能直接当作全部任务完成。

## 本期不纳入

SR-M3-01 干净 Windows 离线安装按用户决定移出本期，不计通过。Linux、人工注销、常在线部署的睡眠唤醒、手机适配、自动降 tile 重试和公网证书部署不扩展。没有为验收重新启动整台机器或切断整机网络。

## 本轮容易误判的点

- 入站计划使用顶层 `modelId`；输出计划使用 `plan.engine.modelId`。上传测试须经过实际请求契约校验。
- 活动原生日志发布后仍可能持有写句柄。私有验收读取应复用兼容共享方式，不把测试读取冲突当成产品任务失败。
- 大快照落盘后只回传摘要。一次维护的远端保存结果已知而传输失败时，先只读核对原记录，不重新执行维护，也不把原 Unknown 改写为成功。
