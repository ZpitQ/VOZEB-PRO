# M5 增量：全局增强 JPG 交付

## 目标与范围

普通完整图与无保护的全局场景增强，最终交付改为 JPG，减少照片文件体积。沿用项目已有高质量 JPEG 参数：quality 95、4:4:4 色度采样；不新增格式开关或依赖。JPEG 为有损编码，不能承诺每张图片都比 PNG 更小，实际照片的细节与体积分别验收。

原图和完整 AI 推理件独立保留；Worker 协议、策略摘要、回执与内部推理结果仍严格 PNG。仅本地最终交付编码改变，字节、扩展名 `.jpg`、`image/jpeg`、素材登记、真实尺寸和摘要保持一致。无需缩小的全局结果也必须编码 JPG，不直接复用完整 AI PNG。

局部修改和商品保护增强继续使用无损 PNG，保留源画幅与保护区域像素。已发布结果及已暂存的旧 PNG 沿原持久身份读取和恢复，不批量转换、不重跑生图或增强。

## 验收用例

| 编号         | 操作与预期                                                                                                    |
| ------------ | ------------------------------------------------------------------------------------------------------------- |
| SR-M5-JPG-01 | 新全局增强解码为 JPEG，文件后缀、MIME、尺寸、字节数、摘要和公开元数据一致；原图与完整 AI PNG 不变。           |
| SR-M5-JPG-02 | 交付尺寸等于 AI 原生尺寸时仍单独编码 JPG，并记录实际编码耗时；禁止插值放大或裁切。                            |
| SR-M5-JPG-03 | JPG 保存或素材发布中断后，恢复同一暂存文件与子素材身份，不再次推理、下载或重编码；旧暂存 PNG 同样保持原字节。 |
| SR-M5-JPG-04 | 声明 JPEG 但实际 PNG、损坏文件或摘要不符时拒绝发布；失败仍可使用原图。                                        |
| SR-M5-JPG-05 | 局部及商品保护结果保持 PNG 和保护像素不变；预览、版本切换、刷新、下载及增强结果引用遵循真实格式。             |
