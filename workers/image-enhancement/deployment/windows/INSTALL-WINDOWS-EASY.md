# Windows 简化安装

适用于管理员维护的内网 Windows GPU 电脑。安装 GPU 驱动和 Upscayl 后，使用配套的 `ZEB-ImageEnhancement-Windows.zip`；解压目录中的文件应放在一起。

1. 将 Upscayl 文件夹放到解压目录的 `Upscayl` 下，或使用电脑上已有的 Upscayl 安装。
2. 双击 `Install-ZEB.cmd`，允许管理员权限。
3. 确认自动检测的内网 IP 和端口，默认值正确时直接回车，然后确认安装。

安装器自动准备引擎清单、配置和校验值，创建 `applications`、`data`、`back`、`credentials` 等目录，生成 Token 并注册开机自动启动的 Windows 服务。运行组件自带 Node，无需另装 Node。安装时自动扫描 Upscayl `resources/models` 中完整的 `*-4x.bin`／`.param` 文件对，生成每个模型的身份和能力清单。不完整或非四倍模型会列为跳过，不冒充可用模型；CLI 和标准校准模型继续校验配套版本。

安装后双击 `Copy-Token.cmd`，在 ZEB 管理员后台的“AI 高清增强”中填写显示的 HTTP 服务根地址并粘贴 Token。点击“检查连接”会先保存当前连接，再获取远程模型列表；超时默认使用标准请求预算，无需额外填写。选择所需模型并保存、执行样图自检，确认就绪后启用。固定样图校准 GPU 服务，业务任务独立使用所选模型；当前启动实例已有的合格校准结果会复用。请确保 ZEB 后端能够访问所选 IP 和端口；HTTP 内网部署无需证书。

已有安装或后来新增模型时，双击 `Refresh-Models.cmd` 扫描并导入模型。模型变化时使用既有维护机制等待当前任务收尾、备份并重启本服务，保留原 Token、安装身份和任务；模型未变化时保持服务运行。更新后在后台重新检查连接获取列表，并完成新启动实例的一次 GPU 校准。不自动删除已导入模型；原始目录缺少这些模型时会明确拒绝。更新失败保留备份、操作记录和诊断，不能盲目重复安装或初始化。

重复启动入口时，已有安装会显示接入信息并保留配置及 Token。其他目录已有服务、目标目录非空或原安装结果未知时，不会覆盖或重新初始化；按底层安装维护指南继续原操作。升级、保留卸载和恢复继续使用 `Install-Worker.ps1`、`Remove-Worker.ps1` 和既有安装记录。

自动化预检查可执行 `Setup-Worker.ps1 -CheckOnly -ListenHost <本机内网IP>`，只检查，不创建目录、安装或重启服务。运行 ZIP 保持原交付字节，来源材料沿用相应版本的交付集合；简化入口和测试的源码随项目提供。
